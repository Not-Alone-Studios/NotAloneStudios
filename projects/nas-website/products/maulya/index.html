MaulyaOffice software for property valuers

In use with our founding firms

One file for every bank valuation.

Maulya keeps each bank valuation in one file, from the day it comes in to the day it is paid. The office works at a desk in the browser; site engineers work on the phone. Both see the same file.

How it’s built

Three rules the code keeps.

A valuation office hands Maulya its files, its photos and its reports. These are the rules that make it safe to.

01

Each firm’s data, kept apart

Every request carries its firm, and the database draws the same line itself, with row-level rules. One firm’s files never show up in another’s.

02

The server owns every file

Where a file stands, who has it and what happens next are worked out on the server. The desk, the phone and the queue read that one answer, so they can’t say different things.

03

Who did what, and when

Actions on a file are written to an audit trail: who did it, when, and what it was before and after.
